# Privacy Policy — Focus YT

**Last updated:** April 10, 2026

## Overview

Focus YT is a browser extension that hides distracting elements on YouTube. Your privacy is important to us, and this extension is designed to operate with zero data collection.

## Data Collection

Focus YT does **not** collect, store, transmit, or share any personal data whatsoever. Specifically:

- No browsing history is collected
- No personal information is gathered
- No analytics or tracking scripts are used
- No data is sent to any external server
- No cookies are set by the extension
- No third-party services are integrated

## Data Storage

The extension uses Chrome's `storage.sync` API solely to save your feature toggle preferences (e.g., whether to hide comments or Shorts). This data:

- Is stored locally in your browser and synced across your Chrome profile
- Contains only boolean on/off values for each feature
- Is never transmitted to the developer or any third party
- Can be cleared by uninstalling the extension

## Permissions

| Permission | Purpose |
|---|---|
| `storage` | Save your toggle preferences locally |
| Host access to `youtube.com` | Inject CSS to hide distracting elements on YouTube pages |

## Changes to This Policy

If this policy is updated, the changes will be posted here with an updated date. Since we collect no data, meaningful changes are unlikely.

# Focus YT

A Chrome extension that removes distractions from YouTube so you can stay focused.

## Features

Toggle any of these on or off from the popup:

- **Homepage Feed** — Hide video recommendations on the home page
- **Sidebar / Related** — Hide related videos next to the player
- **Comments** — Hide the comments section
- **Shorts** — Hide Shorts everywhere
- **Trending / Explore** — Hide Trending in the sidebar nav
- **End Cards** — Hide end screen overlays and cards
- **Autoplay** — Hide and disable the autoplay toggle
- **Notifications** — Hide the notification count badge
- **Live Chat** — Hide live chat on streams
- **Search Suggestions** — Hide search autocomplete dropdown
- **Promos & Banners** — Hide promotional banners
- **Voice Search** — Hide the voice search button

## Install

### From the Chrome Web Store

[Install Focus YT](https://chromewebstore.google.com/detail/moeeaopgdooaggkkaapbcoenlhcnhihj) from the Chrome Web Store.

### Manual / Developer Mode

1. Clone this repo or download the ZIP
2. Open `chrome://extensions/`
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select the `Focus-YT` folder
5. Visit YouTube — distractions are hidden immediately
